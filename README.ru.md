# Speed Dial for Brave

[English](README.md) | **Русский**

Экспресс-панель для новой вкладки: любимые сайты в виде плиток со снимками страниц. Сделана для Brave, работает в любом браузере на Chromium (Chrome, Edge, Vivaldi, Opera). Manifest V3, обычные HTML, CSS и JS без зависимостей.

## Возможности

**Новая вкладка**
- Сетка плиток. На плитке своя картинка, если вы её задали, иначе снимок страницы, иначе значок сайта на цветном фоне (цвет вычисляется из домена).
- Плитка **+** добавляет сайт. При наведении на плитку появляются кнопки ✎ (изменить) и ✕ (удалить).
- Порядок плиток меняется перетаскиванием.
- Строка поиска использует поисковик браузера по умолчанию.
- Настройки (⚙): число колонок (3–10), размер плиток (120–280 px), показ названий, фоновые изображения, экспорт и импорт резервной копии в JSON.

**Смена фона**
- В качестве фона можно добавить одну или несколько своих картинок. Большие картинки при добавлении уменьшаются до размера экрана и сжимаются, чтобы не раздувать хранилище.
- Если картинок две или больше, фон меняется сам: **при каждой новой вкладке** или **через заданное время** — интервал вводится в минутах (от 1 до 10 080, то есть до недели).
- Порядок: по очереди или случайно. Новая картинка проявляется плавно.
- Щелчок по миниатюре в настройках сразу показывает эту картинку, ✕ удаляет её.

**Кнопка на панели инструментов**
- Добавляет текущую страницу на панель в один клик вместе со снимком видимой части страницы.
- Если сайт уже есть на панели, его плитка обновляется, а не дублируется.
- Добавить можно только обычные сайты (http/https). Служебные страницы вроде `brave://` добавить нельзя.

**Языки:** русский и английский. Язык выбирается по языку интерфейса браузера.

## Установка

Расширения пока нет в магазине, поэтому оно ставится как распакованное:

1. Скачайте или клонируйте этот репозиторий.
2. Откройте `brave://extensions` (или `chrome://extensions`).
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное** и выберите папку проекта.
5. Откройте новую вкладку. Если браузер спросит, оставить ли изменённую страницу новой вкладки, оставьте.

> **Не переносите папку после установки.** Идентификатор распакованного расширения зависит от пути к папке. Если путь изменится, браузер посчитает его новым расширением с пустым хранилищем, и плитки пропадут. Перед переносом или переустановкой сделайте экспорт в настройках.

Чтобы обновить расширение, замените файлы и нажмите ↻ на его карточке в `brave://extensions`.

## Приватность и разрешения

Плитки, снимки и настройки хранятся локально в браузере (`chrome.storage.local`). Расширение никуда не отправляет данные, своих серверов у него нет.

| Разрешение | Зачем |
|---|---|
| `storage`, `unlimitedStorage` | Хранить плитки, снимки, фоновые картинки и настройки локально |
| `favicon` | Показывать значки сайтов из кэша самого браузера |
| `search` | Искать через поисковик по умолчанию |
| `activeTab` | Узнать адрес и заголовок текущей вкладки и сделать её снимок — только когда вы нажимаете кнопку расширения |

## Резервная копия

Настройки → **Экспорт** сохраняет в JSON-файл плитки, настройки и, если стоит галочка, фоновые картинки. С фонами файл получается больше. **Импорт** восстанавливает всё из такого файла и заменяет текущие плитки. Если фонов в файле нет, текущие фоны остаются. Копии из старых версий с одной фоновой картинкой тоже поддерживаются.

## Разработка

Сборки нет: правите файлы и нажимаете ↻ на карточке расширения.

| Файл | Назначение |
|---|---|
| `manifest.json` | Манифест расширения (MV3) |
| `defaults.js` | Общий код: переводы, плитки по умолчанию, работа с адресами |
| `newtab.html` / `.css` / `.js` | Страница новой вкладки |
| `popup.html` / `.css` / `.js` | Окошко на кнопке расширения |
| `_locales/{en,ru}/messages.json` | Тексты интерфейса |
| `icons/` | Иконки расширения |

Проверка синтаксиса:

```bash
cat defaults.js newtab.js | node --check -
cat defaults.js popup.js | node --check -
```

Чтобы добавить новый текст интерфейса, добавьте ключ с одним и тем же именем в `_locales/en/messages.json` и `_locales/ru/messages.json`. В HTML пометьте элемент атрибутом `data-i18n` (или `data-i18n-placeholder`, `data-i18n-title`, `data-i18n-alt`), в JS используйте `msg('ключ')`. Чтобы проверить английский в русском браузере, запустите Brave с ключом `--lang=en`.
