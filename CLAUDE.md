# Speed Dial for Brave — экспресс-панель для новой вкладки

Отвечай пользователю на русском языке.

## Что это

Расширение для Brave (подходит для любого браузера на Chromium, Manifest V3). Оно заменяет страницу новой вкладки на экспресс-панель с плитками сайтов, как Speed Dial в Opera. Сборки нет: обычные HTML, CSS и JS без фреймворков и зависимостей. Сейчас расширение ставится как распакованное, через `brave://extensions` → «Режим разработчика» → «Загрузить распакованное». Текущая версия указана в `manifest.json`.

## Языки интерфейса

Расширение работает на русском и английском через `chrome.i18n`. Тексты интерфейса в коде не пишутся: все строки лежат в `_locales/ru/messages.json` и `_locales/en/messages.json`.

- **Новый текст добавлять сразу в оба файла** с одинаковым ключом. Набор ключей в двух файлах должен совпадать.
- `default_locale` в манифесте — `en`. Английский показывается во всех браузерах, кроме русскоязычных. Без `default_locale` расширение с папкой `_locales` не загрузится.
- Название, описание и подсказка значка в манифесте задаются как `__MSG_ключ__`.
- Язык выбирается по языку интерфейса браузера. Переключателя в настройках расширения нет.
- В HTML переводимые элементы помечаются атрибутами `data-i18n` (текст), `data-i18n-placeholder`, `data-i18n-title` и `data-i18n-alt`. Их заполняет `localizePage()` из `defaults.js`, её вызывают `newtab.js` и `popup.js` при старте. `data-i18n` заменяет весь текст элемента, поэтому в `<label>` с полем ввода текст оборачивается в `<span data-i18n="…">`.
- В JS строки берутся через `msg(ключ, ...подстановки)`. Подстановки в сообщении задаются через `placeholders` (см. `confirmDelete`).
- Ключ `htmlLang` хранит код языка (`ru`/`en`). Он идёт в атрибут `lang` у `<html>` и в адрес Википедии в `DEFAULT_TILES`.
- Чтобы проверить английский, запустить Brave с ключом `--lang=en` или сменить язык интерфейса браузера.

## Что оно делает

**Новая вкладка (`newtab.html`):**
- Сетка плиток. На плитке своя картинка, если она задана, иначе снимок страницы, иначе значок сайта на цветном фоне. Цвет фона вычисляется из домена. Если значок не загрузился, показывается первая буква.
- Плитка «+» добавляет сайт. При наведении на плитку появляются кнопки ✎ (изменить) и ✕ (удалить, с подтверждением).
- Порядок плиток меняется перетаскиванием (HTML5 drag & drop).
- Строка поиска использует `chrome.search.query`, то есть поисковик по умолчанию. Запасной вариант — Brave Search.
- Настройки (⚙): число колонок (3–10), размер плиток (120–280 px), показ названий, фоновое изображение (хранится как data URL), экспорт и импорт резервной копии в JSON.
- Слушает `chrome.storage.onChanged`, поэтому плитки, добавленные через значок, появляются сразу, без перезагрузки. Во время перетаскивания обновление пропускается.

**Окошко на значке расширения (`popup.html`):**
- Берёт адрес и заголовок активной вкладки и делает снимок через `chrome.tabs.captureVisibleTab`. Снимок обрезается по верху страницы и уменьшается до 480×300 JPEG.
- Добавляет сайт на панель или, если он уже есть, обновляет его плитку. Совпадение адресов определяет `urlKey`.
- Принимает только адреса http и https. Служебные страницы (`brave://`, магазин расширений) добавить нельзя.

## Хранение данных

Всё лежит в `chrome.storage.local` (с разрешением `unlimitedStorage`):

```js
tiles: [
  { url: 'https://…', title: '…', image: '' /* URL своей картинки */, shot: '' /* data URL снимка */ }
]
settings: { columns: 5, size: 180, showTitles: true, bg: '' /* data URL обоев */ }
```

- Пока `tiles` ни разу не сохранялись, `loadTiles()` возвращает `DEFAULT_TILES`. Любой код, который пишет плитки, должен сначала читать их через `loadTiles()`, иначе плитки по умолчанию потеряются.
- Порядок отображения картинки на плитке: `image` → `shot` → значок.
- Экспорт и импорт используют формат `{ tiles, settings }`. При изменении модели данных импорт старых файлов должен продолжать работать.

## Разрешения

`storage`, `unlimitedStorage`, `favicon` (значки через `chrome-extension://<id>/_favicon/?pageUrl=…&size=64`), `search`, `activeTab` (адрес вкладки и снимок в окошке). Новые разрешения добавляй только при реальной необходимости. Широкие разрешения (`<all_urls>`, `tabs`, `history`) усложнят проверку в Chrome Web Store.

## Важные ограничения

- **Скрипты подключаются обычными `<script>`, без модулей**, поэтому у них общая глобальная область. `defaults.js` подключается до `newtab.js` и `popup.js`. Не объявляй в них заново то, что уже есть в `defaults.js`, — повторный `const` даёт SyntaxError, и страница не работает целиком.
- **CSP в MV3 запрещает встроенные скрипты** (`<script>…</script>`, `onclick="…"`). Только внешние файлы и `addEventListener`.
- Внешние скрипты подключать нельзя: весь код должен лежать в расширении.
- **Идентификатор распакованного расширения зависит от пути к папке.** Если путь сменится, браузер создаст новое расширение с пустым хранилищем. Папку не переносить, перед рискованными изменениями делать экспорт.
- Снимки и обои хранятся как data URL, поэтому размер картинок надо держать маленьким: снимки ≤ 480×300 JPEG 0.8.

Проект — git-репозиторий, ветка `main`. Служебные файлы (`.claude/`, файлы ОС и редакторов, упакованные `.crx`/`.zip` и ключи `.pem`) исключены в `.gitignore`.

**Коммитить и пушить только с явного разрешения пользователя.** Разрешение действует на одну операцию: согласие на один коммит или пуш не распространяется на следующие. Перед коммитом показать, какие файлы в него войдут.

## Как проверять изменения

1. Проверить синтаксис вместе с общим файлом (в Bash): `cat defaults.js newtab.js | node --check -` и то же для `popup.js`. Проверить, что `manifest.json` и оба `messages.json` — валидный JSON, а наборы ключей в двух `messages.json` совпадают.
2. Попросить пользователя нажать ↻ на карточке расширения в `brave://extensions` и открыть новую вкладку. Ошибки смотреть так: в консоли новой вкладки (F12) или правой кнопкой по окошку → «Просмотреть код».
3. После каждого заметного изменения повышать `version` в `manifest.json`.
